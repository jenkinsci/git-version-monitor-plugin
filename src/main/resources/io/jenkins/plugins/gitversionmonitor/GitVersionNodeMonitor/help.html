Shows the version of Git installed on each node, for example 2.43.0. Hover over the value to see the full version, for example 2.43.0.windows.1.

If a node has an older Git than the controller, the value is shown in orange with a warning icon, like the Free Disk Space monitor, and the tooltip also shows the controller's version. A node with a newer Git than the controller is not flagged.

The information is read on the node itself by running git --version, so it reports the Git found on the agent's PATH. Nodes without Git show N/A.
